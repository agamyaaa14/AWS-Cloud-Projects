## What is Cloud?

Before cloud computing, we had to rely on our own physical devices 
Now with cloud computing, we can access whatever we want like music, TV shows etc within an instant.

### What is AWS?

AWS is Amazon Web Services a cloud platform enabling storage and services over the internet anywhere to anyone.

AWS professionals help build and maintain cloud computing, services and usage.
Some popular cloud career paths include Cloud Architect, Devops, Security and Data Engineers.
Today, I'm most interested in Data Engineering because I have more experience in that field through my academic journey.
