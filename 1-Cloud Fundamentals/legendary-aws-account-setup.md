## Introducing Today's Project!

In this project, I'm going to set up my AWS Free Tier account so I can start learning and working with AWS cloud services.

### Key tools and concepts

The key tools I used include the AWS Management Console and Multi-Factor Authentication (MFA).
Key concepts I learned include basic cloud account setup, account security, and monitoring usage to avoid unnecessary charges.

### Challenges and wins

This project took me approximately 20–30 minutes.
The most challenging part was setting up MFA correctly, but once I completed it I understood how important it is for protecting a cloud account.

---

## Creating My AWS Account

In this step, I'm going to set up my AWS account, verify my email, and create a strong password so that I can securely access AWS services.

### Understanding the root user

I learned that a root user is the main account owner and has full authority over all AWS services and settings. Because of this, it is important to create a strong password and secure the account properly so it cannot be easily accessed by anyone else.

---

## Setting Up Billing and Payment

In this step, I'm going to choose my account plan, enter my contact information, and add a payment method so that the AWS account can be activated.


### Why AWS requires a payment method

I learned that AWS requires a payment method mainly to verify that the user is a real person and not a bot, and also to handle charges if the usage goes beyond the free tier limits.

---

## Completing Account Activation

In this step, I'm going to confirm my identity so that my AWS account can be activated and ready to use.

### Identity verification and support plan

I verified my identity by providing my UPI details and enabling autopay verification.
The Basic Support Plan gives access to documentation and resources needed to get started with AWS services while using the Free Tier limits.

---

## Enabling Free Tier Alerts

In this step, I'm going to enable billing alerts so that I receive email notifications about my AWS usage.

![Image](http://learn.nextwork.org/happy_azure_swift_duck/uploads/aws-account-setup_j6k1l7m3)

### Why usage alerts matter

I set up usage alerts because they help me track my usage and make sure I don’t accidentally exceed the AWS Free Tier limits and incur charges.

---

## Securing the Account with MFA

In this step, I'm going to enable Multi-Factor Authentication (MFA) to add an extra layer of security to my AWS account.
I set up MFA using a passkey and authenticator app, which works by scanning a QR code from AWS. After this, the app generates a temporary code that must be entered along with the password when logging in, making the account much more secure.
